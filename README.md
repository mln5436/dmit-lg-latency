## 延迟数字为什么对不上：去程、回程、测试方式都在影响结果

同一台 DMIT 香港机器，有人 ping 出 12ms，有人 ping 出 48ms，两边都没说谎。

原因有三个。

**第一，去程和回程是两条路。** 你 ping 服务器时，数据包出去走一条路，回来走另一条路。DMIT 的路由优化重点在回程（也就是服务器把数据传给你的方向），因为建站、看视频、下载这些场景里，下行数据量远大于上行。所以别人测的"延迟低"，很可能指的是回程路由漂亮，而你的去程还在绕路。

**第二，测的人在哪。** 香港节点对华南用户能做到 10ms 级，华北用户普遍在 40ms 上下；东京节点对华东、华北用户明显更友好。地理位置是硬约束，没有哪条线路能全国一视同仁。

**第三，用什么命令测。** ICMP ping 只能测"通不通、大概多远"，很多机房对 ICMP 限速会给出虚高数值。真要判断线路质量，标准做法是 TCPing 或 mtr——mtr 能同时看到每一跳延迟和丢包，哪个节点开始变慢一目了然。

> 一个实用判断：延迟差 20ms 以内，日常使用基本感知不到；但丢包从 0% 变成 3%，你会在 SSH 打字时明显感觉到"卡顿感"。对线路机来说，稳定性比延迟数字更值得盯。

## DMIT 三个机房到国内的延迟区间

以下区间综合自多个第三方测评的实测数据，不同省份、不同运营商会有出入，当作量级参考即可。

| 机房 | 到国内三网延迟 | 说明 |
| --- | --- | --- |
| 中国香港（HKG） | 约 20–50ms，华南可低至 10ms 级 | 全系最低，物理距离决定 |
| 日本东京（TYO） | 约 50–80ms（电信 55–70ms / 联通约 52ms / 移动约 54ms） | 华东华北表现好于洛杉矶 |
| 美国洛杉矶（LAX） | 约 140–180ms，三网普遍低于 170ms | 距离最远，但 Pro 系列晚高峰波动小 |

有测评记录到 DMIT 洛杉矶 Pro 的 TCPing 三网结果在 160ms 左右，且全天走势接近一条直线，晚高峰没有明显抬升——这条记录比"平均值"更有参考价值，因为它反映的是**抖动幅度**。

反过来，洛杉矶 T1 国际线路就没这个待遇。有路由追踪记录显示，从 LAX.T1 到北京教育网方向，流量先经 Arelion（AS1299）到东京，第 7 跳接入中国电信互联节点时延迟已经到 156ms，第 8 跳涨到 192ms。也就是说，T1 是**绕日本**再进国内，且不针对中国大陆做优化——官方对 T1 的定位也是"优化亚洲-美洲及美洲内部互联，不含中国优化"。

如果你买 T1 是为了让国内用户访问，那延迟区间不是 160ms，而是 190ms 起步，还伴随绕路带来的不确定性。

## 四条线路，延迟差在哪里

DMIT 的产品线按线路分四类，延迟表现差异很大：

**Premium（.Pro）——三网回程 CN2 GIA。**
洛杉矶 Pro 的去程是：电信走 GIA（AS4809），联通直连 AS4837，移动走香港移动（AS58453）；回程三网统一走 CN2 GIA（AS4809）。CN2 GIA 是中国电信的精品承载网，特点是绕行少、不挤公共交换节点，所以晚高峰不容易堵。电信用户在这条线上体验最好。

**Eyeball（.EB）——CMIN2 / 9929 组合。**
洛杉矶 EB 的三网回程走 CMIN2，具体是电信 AS9929/AS58807 负载均衡、联通 AS9929、移动 AS58807。有长期用户的对比测试指出：EB 走联通 9929 时延迟比 Pro 稍高，且在国内侧多几跳。好处是 EB 给的带宽和流量通常比同价位 Pro 更大——拿延迟换流量，是个明确的取舍。

**Tier 1（.T1）——纯国际 BGP。**
上游是 telia、zayo、cogent、Arelion 这类国际 Tier 1，价格最低（入门 $36.9/年），但和国内访问速度没关系。适合面向海外用户的业务，或纯做落地的中转机。

**香港 EB——一个容易被误解的产品。**
香港 EB 回程走三网 CMI，电信去程 via CTG GIA，联通去程经 CTG（跨境段 4837，在香港交换至 23764），移动去程 via CMI。它的卖点是移动网络体验，不是"香港通用低延迟"。有测评者直言香港 EB 性价比一般，如果你主要用户是电信，Pro 更值。

## 下单前怎么测：官方 Looking Glass 和测试 IP

这是本文最实用的一段。

DMIT 官方提供了 Looking Glass 工具，地址是 `lg.dmit.sh`，覆盖洛杉矶、香港、东京全部在售节点，支持 Ping、Traceroute、MTR，还有带宽测试。

它和普通 ping 的区别在于：**你是在从 DMIT 的服务器往你的方向测**，也就是测回程。官方还整理了各节点的测试 IP，你可以直接在自己电脑上对测试 IP 发 ping 或 TCPing，两边对照。

| 节点 | 线路 | 测试 IPv4 |
| --- | --- | --- |
| 洛杉矶 Pro | 三网 CN2 GIA | 154.17.2.2 / 154.17.30.96 |
| 洛杉矶 EB | 三网回程 CMIN2 | 154.17.229.24 / 154.17.226.2 |
| 洛杉矶 T1 | 国际线路 | 174.136.204.135 |
| 香港 Pro | 电信 CN2 GIA + 联通 9929 + 移动 CMI | 103.117.100.199 |
| 香港 EB | 回程三网 CMI | 154.12.188.3 |
| 香港 T1 | 国际线路 | 154.12.176.28 |
| 东京 Pro | 三网 CN2 GIA | 154.12.190.32 |
| 东京 T1 | 国际线路 | 154.31.112.5 |

具体测法，三步：

1. 在你自己的电脑上 `ping 测试IP -t`（或 Windows 用 `tcping`）跑两分钟，记下平均延迟和丢包率。洛杉矶 Pro 电信 150–170ms 属正常，香港节点 10–30ms 属正常；丢包率超过 5% 就要警惕。
2. 打开 `lg.dmit.sh` 选对应节点，输入你自己的公网 IP，跑一次 MTR。重点看**回程经过哪些骨干节点**——出现 CN2 GIA（AS4809）、AS9929、CMIN2 说明线路对板；如果是普通 1299/3356 国际线路，那你走的就是 T1 那一档。
3. 同一个测试在晚上 20:00–23:00 再做一遍。**白天和晚高峰的差值**才是这台机器值不值钱的关键指标。

## 按运营商和地区选线路

不用纠结太久，判断路径基本是固定的：

- **电信用户**：优先 Pro（CN2 GIA）。回程走 AS4809，是国内电信方向优化最彻底的档位。
- **联通、移动用户，且流量需求大**：EB 更划算。联通 9929、移动 CMIN2 都是对应运营商的精品线路，延迟比 Pro 高一档但带宽流量给得更多。
- **华南用户、对延迟极度敏感**（实时 API、游戏、量化类）：香港 Pro，20–50ms 的区间是其他两个机房给不了的。代价是价格，香港 Pro 入门款月付 $39.9，是东京 Pro（$21.9/月）的近两倍。
- **华东华北用户，想要比洛杉矶更好的延迟但不想付香港的价**：东京 Pro，$21.9/月起，50–80ms 区间。
- **主要面向海外用户**：T1，$36.9/年起，别指望它优化国内。

## 几个和延迟、稳定性相关的问题

**流量用超了会断网吗？**
洛杉矶 Pro 和 EB、以及三地 T1 都属于达量限速不停机：超出月流量后降到 4Mbps–100Mbps 继续跑，机器不关机。香港和日本的 Pro 系列则是超量暂停，这点在选购时容易忽略。

**IP 被墙了怎么办？**
DMIT 的政策是每 15 天可以免费换一次 IP（限 IP 不通的情况），其他情况换 IP 收费 5 美元一次。这个价格在同类商家里算便宜。

**延迟会不会晚高峰突然跳高？**
CN2 GIA、AS9929、CMIN2 这类精品线路的核心价值就在这里。有长期用户的记录显示，洛杉矶 Pro 晚高峰延迟和白天差值很小。但这不是绝对值保证——你自己的本地出口线路质量同样是变量，这也是为什么强烈建议先测再买。

**有优惠码吗？**
目前 DMIT 主要走直接标价和补货限时特价，没有需要填写的通用优惠码。看到"独家优惠码"类文章时，建议先去官网核对实际下单金额。

**有什么需要提前知道的缺点？**
有第三方测评提到 DMIT 做宿主机维护时不一定会提前发邮件通知，对可用性要求极高的业务需要留意这一点。另外它的退款政策执行较严格，下单前把条款读一遍。

**付款方式？**
支持支付宝、微信支付、PayPal 和信用卡，有中文客服，国内用户下单没什么门槛。
